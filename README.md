## Tecnologias Utilizadas
- Linguagem: Lógica com sintaxe inspirada em Python
- Paradigma: Programação Orientada a Objetos
- Estruturação de dados: JSON
- Plataforma de execução: Web (HTML5)
- Arquitetura: Organização modular e orientada a componentes

## Características do Sistema
- Interface interativa e responsiva
- Experiência do usuário estruturada para ser prática e intuitiva
- Sistema completo de salvamento e carregamento de dados utilizando JSON
- Estruturação de dados reutilizável e organizada
